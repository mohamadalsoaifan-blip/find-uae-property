Why

To reply to your request (you give this permission with the required box).

To introduce you to ONE licensed UAE real-estate advisor or developer sales team — only if you ticked the separate sharing box. Each introduction is approved by a person first.

To measure which pages and channels help buyers, using counts only.

Anonymous statistics

The page counts steps (for example “step 3 reached”) with a random identifier that lives only in this browser tab. We use no cookies, no advertising trackers and no fingerprinting. Your first-visit source (for example “google”) is kept in your browser's local storage so your request can be attributed correctly.

Your IP address is never stored; a one-way hash is used only to block abuse.

Your choices

We keep your request only as long as needed to handle it.
