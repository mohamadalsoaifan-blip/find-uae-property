# Find Your UAE Property

Static landing page (English + Arabic) for buyers looking for property in the UAE. An introduction service, **not a
real-estate broker**: with the buyer's separate consent, a request is introduced to one licensed advisor.

This repository contains only the built page files. No keys, secrets or buyer data are stored here; requests are
sent to a separate, private backend. The page is generated by `bin/build-site.ts` in the private project — edit it
there, not here.
